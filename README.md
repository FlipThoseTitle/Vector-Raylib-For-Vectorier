# Vector-Raylib
Port of the game Vector to the Raylib framework

This was made with debugging the game in mind.

## Controls

- Esc - Pause the game
- F - Next frame (only when paused)
- S - Slow Mode
- A - Shows areas
- P - Shows platforms
- T - Shows triggers
- N - Shows model nodes
- E - Shows model edges
- D - Shows model detectors
- B - Shows model Bounding box and Collision box if it has
